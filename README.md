# DEEPWILD: Shattered Lands

A 2D pixel-art survival sandbox for Android, built with Godot 4.5.1.

## Development plan
- First: stable offline single-player prototype.
- Later: online co-op lobbies for up to four players.

## Controls
- Left side: analog movement joystick.
- Right side: jump, attack, and context action buttons.

All development and Android builds are automated with GitHub Actions.
